# tetris

A clean-room, from-scratch re-implementation of the idea behind **[ospann/tetris](https://github.com/ospann/tetris)** by [@ospann](https://github.com/ospann). The original project had no open-source licence, so no code or assets were copied: only the concept (and its public description) was used as inspiration. All code and assets in this repository are original.
